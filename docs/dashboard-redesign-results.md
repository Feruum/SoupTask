# Soup dashboard redesign — 2026-11-10

Реализован утверждённый `output/imagegen/04-dashboard-dribbble-v2-dark.png`: единая аналитическая область с круговой картой, группами model → method → run, выбранным запуском, настоящим uPlot Loss и лентой наблюдений. Поддержаны тёмная и белая темы, мобильная компоновка. История запусков сохранена.

Карта использует реальные сводки каталога: цвет обозначает группу модели/метода, длина плиток — количество конечных наблюдений по логарифмической шкале, ромбы — находки качества. Точные числа доступны в таблице. Значения метрик не анимируются через промежуточные числа. Общие анимации навигации сохранены.

## Команды и реальные результаты

- `npm run build` — успешно, TypeScript и production-сборка Vite.
- `npm run lint` — успешно, предупреждений нет.
- `npm test` — 81/81 тест, 17 файлов. Снимок отчёта: `reports/dashboard-redesign/unit-results.json`.
- `npx playwright install chromium` — выполнено перед браузерной проверкой.
- `npm run test:e2e -- --config tmp/dashboard-redesign/playwright.config.ts --output tmp/dashboard-redesign/final-test-results` — 29/29, Chromium, около 1,6 минуты. Отчёт: `reports/dashboard-redesign/e2e-results.json`.

На этой Windows-машине команды выполнялись через локальный `tmp/tooling/bin/npm.cmd` с bundled Node в PATH.

Первый запуск браузера из ограниченного окружения не нашёл Chromium. Браузерные проверки затем выполнены с необходимым доступом к установленному браузеру. Первые проверки нового интерфейса выявили несовпадение доступных имён групп и неоднозначные подписи select: исправлены. Первый общий прогон дал 28/29 из-за отсутствующего hover-readout на странице запуска; его результат сохранён в `e2e-before-shared-chart-refresh.json`. После параллельного обновления общего компонента графиков проект пересобран; финальный полный прогон прошёл 29/29. Общий компонент графиков не переписывался в рамках редизайна.

Проверены выбор run/метрики на карте и с клавиатуры, переходы к исходным данным, группы, история, отсутствие горизонтального переполнения и axe в обеих темах. Отдельная проверка Canvas подтвердила нарисованный пик исходной точки 500001 со значением 100. Это конкретное свидетельство сохранности пика, а не общее доказательство корректности любых миллионных рядов.
